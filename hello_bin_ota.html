打包头格式（256 字节头区域 + 固件镜像，文件总大小 = 256 + 固件长度）：CRC8(1) + 分区O32(3) + 空格 + 型号OY32(4) + 2空格 + FW_版本(9) + 空格 + HW_版本(7) + 空格 + 4字节大端固件长度(4) + 0xFF填充(223)，随后为固件镜像。
格式依据 OY32 实际固件包（APP.bin / OTA 包）与设备端 BOOT 源码（SPI_FlashReadForCrc8）验证；CRC8 为 CRC-8/MAXIM（多项式 0x8C 反射、初值 0x00），计算固件镜像前 4 字节对齐部分。
